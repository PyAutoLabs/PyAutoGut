# Group extra galaxies: truncated dPIEMass + truncation docs across packages

Type: feature
Target: autolens_workspace
Difficulty: medium
Autonomy: supervised
Priority: medium
Status: formalised

## Original request (verbatim)

> For the group and cluster packages, the extra galaxies should be truncated and
> therefore use dPIEMass, with clear documentaiton on why this is the case.
> Therefore, also mention how in imaging, interferometer, point_source, multi
> galaxy that they use Isothermal and thus are not truncated, but that group and
> clsuter do you truncation.

## Context

- @autolens_workspace `scripts/cluster/` already uses `dPIEMassSph` throughout
  (Lenstool-native `sigma`/`r_cut`, `r_core = 0`) — cluster members and
  scaling-tier galaxies are truncated. No mass-profile change needed there;
  only the "why truncation" documentation needs to be made explicit.
- @autolens_workspace `scripts/group/` currently models its extra galaxies
  (member galaxies) as `IsothermalSph` — untruncated — across ~45 scripts
  (main examples `start_here.py` / `modeling.py` / `fit.py` / `simulator.py` /
  `slam.py` etc. plus every `features/` sub-package). These should become
  truncated `dPIEMassSph`, mirroring the cluster convention.
- The galaxy-scale packages (`imaging`, `interferometer`, `point_source`,
  `multi_galaxy`) use `Isothermal`/`IsothermalSph` for extra galaxies in their
  `features/extra_galaxies/` examples — correct as-is (a single nearby
  perturber; truncation unnecessary), but the docs should state this and
  cross-reference the group/cluster truncated convention.

## Scope

- `scripts/group/`: switch extra-galaxy mass models `IsothermalSph` →
  `dPIEMassSph` (simulators and model composition), following the cluster
  package's Lenstool-native parameterization conventions.
- Add clear documentation in group + cluster explaining WHY member galaxies are
  truncated (tidal stripping in dense environments; dPIE `r_cut`), in the
  main example docstrings.
- Add a short documentation note in the `features/extra_galaxies/` examples of
  `imaging`, `interferometer`, `point_source` and `multi_galaxy`: they use
  `Isothermal` (untruncated) and why that is fine at galaxy scale, pointing to
  group/cluster for the truncated dPIE convention.
- Group simulated datasets are regenerated by the simulators where the mass
  model changes (delete dataset dirs so `should_simulate` re-fires).
- Mirror the same prose in the generated notebooks via the standard
  `generate.py` flow.
